# Alloy Tone Lab

一个与 Unity 运行时隔离的本地声音实验台。顶部先展示 14 条已经组合好的完整音效；选择其中一条后，面板再把它按时间拆成：

1. **首段**：触发瞬间的第一下 Click，决定清脆感和重量；
2. **主段**：紧跟第一下出现的合金鸣响，决定材质与音高；
3. **尾段**：主段自然消失的部分，只决定拖多久，不会产生第二下撞击。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 8877 --directory tools/alloy-sound-lab
```

然后打开：

```text
http://127.0.0.1:8877/
```

如果从 `file://` 打开 `index.html`，页面会尝试自动跳转到上述本地服务地址；因此仍需先启动这条服务器命令，否则浏览器无法载入音频素材。

## 使用建议

- 第一步只做一件事：在最顶部点击一条完整音效。点击后会自动试听，并把这条声音的全部参数载入下方。
- 再点“只听首段”，把第一下调到既厚重又清脆。
- 再点“只听主段”，选择合金音色，并调节主段音高和响度。
- 最后点“只听尾段”，用“消散时长”决定声音要拖多久。
- “首段音高”只改变第一下；“主段音高（频率）”只改变后面的合金鸣响，两者互不影响。
- “金属复杂度”越低越纯净，越高越像结构复杂的小型合金件。
- 拆分区里的三张分段卡片也可以直接点击，试听对应段落。
- 调整参数后，顶部被选中的音效会标记为“已调整”；“恢复这条音效”只恢复当前选择，不会跳回其他音效。
- A/B 槽会保存在浏览器 `localStorage` 中。
- “导出 WAV”输出 48 kHz、16-bit、stereo 文件；“导出参数”输出 JSON。

## 产品状态

这是研究工具，不是 `unity/FidgetingApp` 的运行时功能。导出的声音或参数只有在进入 Unity、完成场景接线、测试并更新 `Docs/IMPLEMENTATION_STATUS.md` 后，才可称为已集成。
