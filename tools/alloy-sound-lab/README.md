# Alloy Tone Lab

一个与 Unity 运行时隔离的本地声音实验台。页面顶部新增了“三叶陀螺风声模拟器”，用 Web Audio 实时合成连续风声：

- 转速决定整体响度、频谱与每秒叶片经过次数；
- 厚重感控制低频空气体量；
- 切风清晰度控制中高频边缘；
- 叶片脉动只添加轻微的三叶经过纹理；
- 金属共鸣添加两组低电平、非整数比的合金模态；
- 停转消散会让实际叶片经过频率、切风频谱与响度同步减速，而不是只做音量淡出。

转速为零时保持静音。模拟器只生成声音，不会给 Unity 陀螺施加任何转速；正式接入时应由运行时真实角速度驱动。

下方继续展示 17 条已经组合好的完整 Click 音效；选择其中一条后，面板再把它按时间拆成：

1. **首段**：触发瞬间的第一下 Click，决定清脆感和重量；
2. **主段**：紧跟第一下出现的合金鸣响，决定材质与音高；
3. **尾段**：主段自然消失的部分，只决定拖多久，不会产生第二下撞击。

前 14 条继续遵守单次 Click。第 15 条“精密按压回弹”是明确的双触点例外：首段为较厚实的按压，主段为短促机构回响，尾端为更小、更亮的独立回弹 Click；选择它时，“消散时长”会自动改成“按压到回弹间隔”。

第 16 条“罐头币按压 · 视频原声”来自用户提供的小红书参考视频。R1/R2 曾误把另一处单击和连续滚珠节奏当成目标，现已废弃。当前 R3 逐帧对齐视频 21.815–23.380 秒的完整按压动作，直接保留“开始受力 → 金属片连续翻转 → 触底收住”共 1.565 秒的原始动作时序；页面不再用单个 Click 人工重复。首、中、尾分别取 0.25 / 0.99 / 0.325 秒，可单独试听。为了避免再次改坏原声，视频内置机构声、三段边界和尾段时长默认锁定，只开放整体音高、厚重度、清脆度和输出音量作轻微听感调整。

第 17 条“罐头币按压 + 回弹 · 纯净提取”分别保留 22.142 秒的真实按压和 23.256 秒的真实回弹。R5 对两声独立执行持续谱/瞬态谱分离、背景谱扣除、155 Hz 高通和短噪声门；回弹不是复制或移调第一声。两声之间按原视频保留约 1.113 秒间隔，默认静音以免背景音乐或底噪重新出现；该间隔可用尾段滑杆手动调整。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 8877 --directory tools/alloy-sound-lab
```

然后打开：

```text
http://127.0.0.1:8877/
```

如果从 `file://` 打开 `index.html`，页面会尝试自动跳转到上述本地服务地址；因此仍需先启动这条服务器命令，否则浏览器无法载入音频素材。

## 使用建议

- 风声区先点“启动风声”，再拖动转速；也可以直接选择低速、中速或高速。
- 调整“厚重感”和“切风清晰度”来找合金陀螺的空气质感；“叶片脉动”建议保持较低，避免出现明显的“呼呼呼”。
- “停转并消散”会按设定的惯性时间平滑收声。
- 进入 Click 区域后，先点击一条完整音效。点击后会自动试听，并把这条声音的全部参数载入下方。
- 再点“只听首段”，把第一下调到既厚重又清脆。
- 再点“只听主段”，选择合金音色，并调节主段音高和响度。
- 最后点“只听尾段”，用“消散时长”决定声音要拖多久。
- 选择“精密按压回弹”时，可分别试听按压、机构回响与回弹；尾段滑杆改为控制两端之间的时间。
- 选择“罐头币按压 · 视频原声”时，可分别试听开始压入、金属片连续翻转和触底收声；这是视频中同一次按压的三个时间片段，不再叠加人造滚珠、Click 或共鸣。
- 选择“罐头币按压 + 回弹 · 纯净提取”时，可分别试听首段按压和尾段回弹；主段代表按住阶段，持续音乐已被主动清除，因此保持静音。
- “首段音高”只改变第一下；“主段音高（频率）”只改变后面的合金鸣响，两者互不影响。
- “金属复杂度”越低越纯净，越高越像结构复杂的小型合金件。
- 拆分区里的三张分段卡片也可以直接点击，试听对应段落。
- 调整参数后，顶部被选中的音效会标记为“已调整”；“恢复这条音效”只恢复当前选择，不会跳回其他音效。
- A/B 槽会保存在浏览器 `localStorage` 中。
- “导出 WAV”输出 48 kHz、16-bit、stereo 文件；“导出参数”输出 JSON。

## 产品状态

这是研究工具，不是 `unity/FidgetingApp` 的运行时功能。导出的声音或参数只有在进入 Unity、完成场景接线、测试并更新 `Docs/IMPLEMENTATION_STATUS.md` 后，才可称为已集成。
