# Fidgeting 产品手感准则

## 目标

通过可信金属视觉、输入预压、脱档、跨档、吸附和质量沉降的同步反馈，让移动端无限接近实体高级指尖玩具令人反复把玩的手感。

屏幕不能向手指施加真实反向力，因此“阻力”必须由三条同步通道共同建立：视觉上的弹性滞后、机械状态中的势垒与快速吸附、Taptic Engine 的预压与触点。任何单独的震动或补间动画都不能称为机械手感。

## 不可破坏的链路

```text
输入 → 机械状态 → 语义事件 → Haptic Recipe → iOS Renderer
```

- Touch、Mouse、Core Motion 只提供输入，不得直接调用 `IosHaptics`。
- 机械模型是位置、速度、档位、脱档、捕获和停止状态的唯一权威。
- `Breakaway`、`DetentCrossed`、`DetentCaptured` 等事件只在相应物理状态真实发生时发出。
- 可见磁体、物理档位和 Haptic 档位必须读取同一个 Profile，禁止维护三份相似数组。
- Library、AUTO、场景构建、Reset 和程序化设姿可以复用视觉物理，但不得伪造用户触感。

## 磁吸推牌基线

第五款 `magnetic-slide-tile` 的唯一配置是 `LinearMagneticDetentProfile`：

| 项目 | 重磁默认值 |
| --- | ---: |
| 稳定档位 | 6；默认第 3 档，左右均有真实磁力井 |
| 磁体中心距 | 13.6 mm |
| 有效行程 | 68 mm |
| 默认双向范围 | 左 27.2 mm / 右 40.8 mm |
| 移动质量 | 55 g |
| 手指耦合 / 阻尼 | 125 N/m / 4.1 Ns/m |
| 脱档力 / 磁力峰值 | 0.62 N / 0.58 N |
| 轨道摩擦 / 阻尼 | 0.085 N / 0.30 Ns/m |
| 捕获弹簧 / 阻尼 | 220 N/m / 3.8 Ns/m |
| 最大可见预压 | 1.4 mm |
| 捕获半径 | 5.8 mm |
| 精确锁定 | 误差 < 0.10 mm 且速度 < 0.0045 m/s |

状态顺序固定为：

```text
Captured → Loading → Breakaway → Traveling → Capturing → Captured
```

相邻档位使用连续磁势阱：

```text
Fmag = -Fpeak × sin(2πq)
```

手指不是滑盖位置，而是弹簧目标：

```text
m·x'' = kh(xfinger-x) - ch·x' + Fmag(x) - crail·x' - Ffriction
```

最大积分子步为 `1/240 s`，每帧最多 8 个子步。捕获完成必须把速度严格清零；边界不能回弹自振；Reset 必须静默、归零并回到第 3 个真实磁力井，而不是单向端点。

## 三层磁吸扇牌基线

第六款 `magnetic-fan-card` 使用独立 `FanCardDetentProfile`，不得继承或改写第五款线性推牌、四款旋转机构及设置面板中的调节状态：

| 项目 | 固定值 |
| --- | ---: |
| 全局稳定档位 | `q = 0 / 1⁄3 / 2⁄3 / 1` |
| 中片 / 顶片角度 | `45°q / 90°q` |
| 相邻层 / 最外层最大夹角 | `45° / 90°` |
| 慢推脱档负载 | `0.050` |
| 慢推手指弹簧 / 阻尼 | `96 / 6.0` |
| 慢推磁峰 / 轨道摩擦 | `6.4 / 0.38` |
| 捕获弹簧 / 阻尼 | `118 / 14.2` |
| 慢推脱档冲量 / 松手预测 | `0.95 / 0.070 s` |
| 可见预压倍率 | `0.24` |
| 快速脱档 / 手指弹簧 / 阻尼 | `0.024 / 220 / 5.2` |
| 快速磁峰倍率 / 摩擦 / 脱档冲量 | `0.50 / 0.16 / 1.8` |
| 慢推 / 快速最高归一化速度 | `2.4 / 5.0 s⁻¹` |
| 快速手势区间 | `0.55→1.30 屏宽/秒` |
| 最大积分子步 / 帧步 | `1/240 s / 1/20 s` |

底片和中片各提供一条以共同轴心为圆心、向左下内缩的 45° 圆弧轨道及 3 枚磁体；中片和顶片各提供一枚随动轴承球。机械坐标只有一个 `q`，模型角度、档位语义和 Haptic 都从该坐标与同一 Profile 读取。慢推使用手指弧度作为连续弹簧目标，逐档越过势垒；速度达到快速区间，或支持压力输入的设备检测到有效压力增量时，机构锁定当前方向的端点目标并逐档快速穿越。反向快速滑动切换到另一端点；低速反向会退出快速路径并在当前位置重新接管。屏幕不具备真实反向力，因此“力度”以滑动速度为主、有效压力增量为辅，不能把普通触摸的固定 pressure 值误判为重按。

只有明确用户拖动可以授权 `Breakaway`、`DetentCrossed`、`DetentCaptured`；快速手势松开后允许物理轨道继续完成已经授权的端点穿越，但仍必须逐档产生语义事件并最终精确归档。手指控制与该段惯性收尾期间暂停 Core Motion 采样，完成后以当前设备姿态重新建立参考。Reset、Library、AUTO 和程序化 `SetFanProgress()` 必须静默。

本款的材质语言与机械配置严格解耦。枪黑珠喷框、暖银金属面、背面铬轴承、金色编织轨道、Oxanium `A/Q/K`、向下极简黑桃、细线与三点蚀刻均为无碰撞展示层。每片正面固定两组标准扑克牌角标：左上 `rank + 小黑桃` 直立，右下同一组绕牌面法线旋转 `180°`；同组字母和黑桃朝向必须一致。详情页每次打开只在整组 `AAA` 与底/中/顶 `Q/K/A` 之间等概率选择一次，不允许三层各自随机；同一张牌两角必须共享同一个 rank mesh。背面不重复正面图案，每个标记必须直接隶属自己的刚性牌片。共同轴心在正面只表现为干净的 bevel 通孔，结构校验用的轴标记不得渲染成额外金属环。更换颜色、粗糙度、法线或正面图案不得改变四档、45°/90°、阻尼、交互热区或 Haptic 配方。

背部轨道与正面 rank 的制造源以 Blender 为准：暗色下沉槽、圆丝金属网、三枚独立磁体和 Oxanium 700 `A/Q/K` 字形都必须是可检查的实体几何，网格开孔必须真实透视而不是透明贴图，字形不得退回依赖相机角度的 TextMesh。运行时只切换所属角标的 `MeshFilter.sharedMesh`，不能复制、叠放或跨层移动 Renderer。滑轨随动点相对共同轴心固定为 `(-49, -27) mm`，完整 `6.2 mm` 宽下沉槽及圆头距圆角牌身外轮廓必须至少 `6.0 mm`；验证必须采样整条外轮廓，不能只检查中心线或端点。Blender 可以为圆头留出不超过约 `3.1°` 的纯视觉余量，但交互有效弧仍固定为 `45°`，三枚磁体仍对应四个全局档位；Unity 导入后只替换 Renderer/MeshFilter，不得用该视觉余量改写 `FanCardDetentProfile`。这些参数只由 `ArtSource/FanCard/fan_card_guardrails.json` 定义，修改后必须通过 `validate_fan_card_guardrails.py`、Unity 几何门禁和 EditMode 回归。

## 视觉与触觉同步

- Loading：滑盖保持在档位，显示最多 1.4 mm 的预压滞后。线性推牌只在同一势垒的 `0.72 / 0.84 / 0.94` 三个空间里程碑发有限边缘提示，停指不持续震动。
- Breakaway / DetentCaptured：机制仍发出语义事件用于状态、测试和视觉，但推牌类专用 Haptic renderer 不额外叠加触点，避免一次跨档被拆成不可控的多次。
- DetentCrossed：线性推牌每跨一个真实势垒发一个有限三层包：`t=0 ms` 主冲击 `0.98 / 0.78`，同时叠加 `30 ms` 低锐度重量段 `0.58 / 0.22`，`t=22 ms` 收尾触点 `0.52 / 0.44`。第二项均为 sharpness，不是马达 Hz。
- 扇牌 DetentCrossed：主冲击随真实跨档速度映射为 `Intensity 0.92→1.00 / Sharpness 0.76→0.90`，叠加 `32 ms` 重量段 `0.64 / 0.24` 与 `t=22 ms` 收尾 `0.56 / 0.42`。
- 视觉沉降 half-life 为 45 ms，120 ms 内强制回零；微回震只作用于 Renderer 子层，不移动 Collider。
- 三层包内的 continuous 仅有 `30–32 ms` 的有限时长，不是常驻/循环 player。唯一循环 `CHHapticAdvancedPatternPlayer` 仍只服务高速旋转纹理，推牌停指、AUTO、Library 和 Reset 必须静默。

## 生命周期与验收

- Haptic 关闭、手指释放、进入 Library/AUTO、Reset、App 后台、切场景和对象禁用时，推牌不得继续输出 Haptic。
- Core Haptics engine reset/stopped 后，不恢复已结束的推牌有限包；只允许符合旋转机制生命周期的常驻 player 按请求恢复。
- 自动测试负责确定性、事件计数、单一配置来源、生命周期连接和无原始 Haptic 调用。
- 触感强弱、六档盲辨、视觉与触觉是否同帧，以及连续 20 次往返是否漏击/双击，只能在支持 Core Haptics 的 iPhone 上最终验收。
- 机械点击音频只消费同一条经过输入授权的 `DetentCrossed` 语义事件；不得另建时间轴，也不得从触摸回调直接发声。

## 后续机构复用

`MagneticDetentTrack1D` 接受任意单调一维档位。线性机构使用米和质量；旋转适配器可把坐标换成弧度、质量换成转动惯量，但必须保留相同状态机、语义事件和生命周期。本轮不迁移既有四款陀螺。
