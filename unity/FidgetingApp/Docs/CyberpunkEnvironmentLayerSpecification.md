# Cyberpunk Environment Layer Specification

本文件是霓虹都市主题以及后续主题场景的固定空间契约。艺术风格可以变化，但层级、遮挡关系、主体锚点和视差方向不能被整体虚化或单张平面构图破坏。

## 固定层级（由远到近）

| 层级 | 赛博场景内容 | 最大位移 | 方向 | 视觉职责 |
| --- | --- | ---: | --- | --- |
| L0a | 远星空：微小、低亮星点 | ±2 pt | 反向 | 最远深度，不形成大面积纹理 |
| L0b | 近星空：少量略亮星点 | ±4 pt | 反向 | 与 L0a 产生星空内部纵深 |
| L1 | 远处城市剪影、薄雾与竖向灯带 | ±8 pt | 反向 | 轮廓可读，窗格和微细节受控 |
| L2 | 设备坞、开启动力舱和与其连续的接近地面 | ±14 pt | 正向 | 场景中景锚点和模型接触依据 |
| L3 | 陀螺、接触阴影、主体光晕 | ±14 pt | 与 L2 同组 | 不与台座“分家”；只叠加材质高光响应 |
| L4 | 右侧近景科技建筑 | ±22 pt | 正向 | 大尺度暗色框架，主要边缘可读 |
| L5 | 左侧最近科技建筑／剪影 | ±30 pt | 正向 | 最大遮挡和最大位移，建立最近层 |
| L6 | 原生 UI、标题、状态与控制 | 0 | 固定屏幕 | 保持贴在玻璃上的稳定感 |

水平位移使用表中满幅；垂直位移为水平的 60%。远景与近景方向相反。L2 与 L3 必须共享同一平移基准，模型高光、反射和呼吸光可以独立变化，但模型几何不能脱离台面。

## 固定构图锚点

- 设备坞宽度约占画面 68%–72%，中心固定在 viewport X = 50%。
- 台面中央透视接触平面位于距画面顶部约 62.4%；后沿可以更高，但不得把模型对齐到后沿。
- Library 模型底沿位于中央接触平面上方约 4 px，表现轻触或极轻悬浮；接触阴影必须落在台面中央。
- 模型建议占画面宽度约 28%–34%，其后方保留安静负空间，但负空间不能抹掉 L0/L1 的纵深依据。
- 选择页显示 L0–L5；详情页可让 L4/L5 退场并做相机推进，但 L2 承托仍保留，L0/L1 不合并成单层。

## 清晰度与焦点规则

- L0 星点保持小而清楚，亮度低；不能因“背景虚化”全部消失。
- L1 使用大气透视和适度柔化，城市整体轮廓、远近尺度与天际线间距必须可读；只压制窗格等高频细节。
- L2 保留清楚的主轮廓、接触面和开舱结构，微划痕与面板噪声降低。
- L3 永远是最清晰、局部对比最高的层；环境光响应不能把产品颜色洗成纯白。
- L4/L5 保留清晰的遮挡边缘和大面转折，内部微细节压入暗部；焦点通过低亮度控制，而不是整体高斯模糊。
- 禁止把 L0、L1、L4、L5 同时做成同一焦平面或同一雾墙。每层至少要靠尺度、遮挡、锐度、空气透视中的两项与相邻层区分。

## 生产资产与防穿帮

- 正式资源必须拆成独立带透明通道的 L0a/L0b/L1/L2/L4/L5；L3 由 Unity 模型、阴影与实时光构成。
- 每层四周 bleed 不小于自身最大位移；L5 建议至少 36 pt，3× 资源至少 108 px。
- 视差只使用 Transform／相机投影，不允许每帧重绘位图。
- Reduce Motion 开启时所有层回到基准位置，只保留模型的低频材质呼吸。
- 页面不可见时停止运动采样和环境光更新。

## 视觉验收

1. 缩到手机截图 25% 尺寸时，第一眼必须仍是模型，第二眼是设备坞，第三眼才是城市和建筑框架。
2. 转为灰度后，L0、L1、L2、L4、L5 的轮廓仍能被分别指出。
3. 倾斜预览中，L2 与 L3 不产生相对滑移；L4/L5 位移明显大于 L0/L1，且方向相反。
4. 任一层移除后都能说明损失的深度职责；纯装饰且没有空间职责的细节应删除。
