# 推牌同源参数化六视图（校正版）

本目录用一份确定性的 Three.js 几何生成全部视图，解决上一版中“左右侧面方向错误”和“顶视图与爆炸图不是同一造型”的问题。图片是视觉级 3D 拆解参考，不是制造 CAD。

## 几何不变量

- 恰好 7 个轴向层级：`L1`–`L7`。
- 恰好 6 颗实体磁铁：`M1`–`M6`。
- 六颗磁铁全部位于同一条水平 X 轴中心线，`y = 0`。
- 六个中心点为 `−4.10, −2.46, −0.82, 0.82, 2.46, 4.10`，统一节距 `1.64`；同一数组同时驱动 `L2/L3/L5/L6`，避免孔、磁体和凹窝漂移。
- `L2`、`L3` 的 6 个通孔、`L5` 的 6 颗磁体和 `L6` 的 6 个承接凹槽严格同轴一一对应。
- `L1` 是连续圆角外框，含 4 个角孔与不遮挡磁体中轴线的 Z/S 镂空肋条。
- 磁体作为独立 `L5` 爆炸层显示，不再嵌在载板里。
- `L4` 的深色周向裙边向下包住 `L4 + L5` 空腔，使装配侧面保持连续，只留下真实层缝；爆炸时裙边仍随导轨/弹簧笼作为一个层级移动。
- `L6` 六个凹窝中心低于载板上表面，薄环基本齐平；组装时 `L5` 磁体底面位于对应凹窝正上方。
- 爆炸图包含六条橙色同轴虚线，分别穿过 `L2 → L3 → L5 → L6` 的六组对应中心。
- 爆炸变换始终只沿 Z 轴：基础层距 `3.0`，`L5` 再向 `L6` 方向移动 `1.1`，用来避开 L4 裙边并同时展示六磁体与六凹窝；没有任何横向错位。
- 所有视图共享签名 `pushcard-7L-6M-inlineX-zs-frame-v2-final`，只改变正交相机及爆炸层距。
- 顶、正、背、左、右装配视图使用完全相同的正交高度 `9.2`；不对短端视图单独放大。由于 `D = 6`、`W = 12`，左右短端的画面宽度应约为正视长边的一半。

## 材质划分

- 喷砂银钛：`L1`、`L6`、`L7`
- 枪灰钛：`L2`
- 深色 POM：`L3`
- 枪灰金属：`L4` 导轨/弹簧笼
- 镀镍金属：独立 `L5` 磁体 `M1`–`M6`

暖橙色只由轮廓灯产生，不作为零件固有颜色。

## 重新渲染

使用 Node 与 Playwright 运行：

```sh
node render.cjs
```

`render.cjs` 会优先使用当前 Node 可解析的 Playwright；否则使用本机 npm/npx 缓存中的最新版本。也可以用 `PLAYWRIGHT_MODULE=/absolute/path/to/playwright` 显式指定。Three.js 固定为 `0.179.1`，模块及其 core 依赖均保存在 `vendor/`，SHA-256：

```text
three.module.js  ce6be0cb5ead0027e1f6094dd82ad43bba0886c03324a3b21fd9a33ac93fc2b4
three.core.js    3cd45beb4da9ce682bb7f5894dafd8a146379aa4b6b5aa3acd9ef5d47fdaaf92
```
