# 推牌拆解线框参考

本目录从高分辨率专利页中单独裁出 9 张结构线框图，用于建立 3D 零件层级、爆炸方向和建模对照板。处理仅包含裁切、灰度化与对比度增强；没有生成、补画或改变原始几何。

> 注意：USD1020916S1 与 CN218011061U 是两套不同设计。它们可以共同说明层级、轨道和磁铁思路，但不能被当作同一产品的完整工程图直接拼装。

## 推荐的 3D 爆炸层级

建议在 Unity/Blender 中先建立以下中性层级，再根据原创设计调整外观：

1. `TopDecorativePanel` - 可替换面板或装饰盖，参考 09。
2. `UpperStructuralShell` - 上部结构壳与连接位，参考 02、05、07。
3. `SliderCarriers` - 滑块或低摩擦载体，参考 08。
4. `MagnetArray` - 磁铁阵列；磁极、间距和吸力需由实物验证，参考 03、08。
5. `GuideAndStops` - 导轨、限位和缓冲结构，参考 08。
6. `LowerShell` - 下壳、底板和侧壁，参考 03、06。
7. `FastenersOrLocators` - 紧固件、定位柱或磁吸定位件，参考 07-09。

爆炸动画统一沿模型局部 Z 轴展开；外壳中心和机构中心应先在装配态完全重合，再为各层设置独立 pivot。正向图可用于平面对齐，透视图只能用于判断厚度和层次，不能直接按像素测量尺寸。
