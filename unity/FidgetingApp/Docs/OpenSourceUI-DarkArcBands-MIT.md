# OpenSourceUI Dark Arc Bands

The native Pack-opening source baseline adapts `DarkArcBandsBackground` from
OpenSourceUI. The original React/Tailwind runtime is not included.

- Project: https://github.com/bidyut10/opensourceui
- Component: `components/background-gradient/dark-arc-bands-background.tsx`
- Pinned source commit: `d239c3463c984a099dd2cb67817a41fc0bcc876f`
- Pinned Git blob: `b13404dd73e02a4267b48ff1136aa3c1b2205827`
- Local adaptation: native SwiftUI; the fixed source palette, RGBA stops,
  ellipse geometry, blur, lift and dot texture are preserved. The decoration
  is identical for every Pack and reads neither Pack tier nor prize rarity.
- Bundled notice: `Assets/StreamingAssets/ThirdPartyNotices/OpenSourceUI-DarkArcBands-MIT.txt`.
