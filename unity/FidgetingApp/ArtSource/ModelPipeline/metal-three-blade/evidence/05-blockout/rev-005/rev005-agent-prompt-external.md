# rev-005 · 给 agent 的执行指令

**Goal:** 用 `spinner_rev005.py` 替换 rev-004 的叶片和盖体台面占比。不要手工建模，直接跑脚本，所有形状由 `P` 字典驱动。

## 执行

1. 打开 rev-004 的 .blend，Text Editor 载入 `spinner_rev005.py`，Run Script。脚本会删除所有 `SP_` 前缀的旧对象后重建：`SP_Body`（带 5 个 Boolean 修改器，切刀对象 `SP_cut_*` 为线框、不渲染）、`SP_Cap`。
2. 场景单位会被设为 mm（scale_length 0.001）。相机、灯光、地面不受影响。
3. 控制台会打印派生量，确认这几行：
   ```
   R_TOT 32.50  R_CAP 17.42  R_IN 18.22  R_DISC 13.88
   Z_TOP 13.50  Z_RIM 11.85  (body top 12.00, rim -0.15 vs body)
   side midpoint radius 19.25  -> wall to bore 1.03 mm
   pocket apex 19.60  -> wall to bore 1.38 mm
   ```
4. 先出 Workbench 白模正交顶视图，再出 Cycles。白模过了再开材质。

## 平面图（这次先把 CAD 搞对）

之前的"三片独立叶片"理解是错的。参考实物的机身是**一块圆角等边三角形**，盖嵌在中心圆孔里，三个角就是所谓的"叶片"。俯视：

- 外轮廓：等边三角形，三个角顶点在 90° / 210° / 330°，落在外径 Ø65 上；角圆角 R9；三条边中点向内凹 1.5 mm（几乎直边）
- 中心：盖孔 Ø36.44（= 盖 Ø34.84 + 暗缝 0.8 × 2），从盖座面 z=7.5 向上打穿；轴承孔 Ø12.8 穿透
- 三个角顶面各一个**三角凹槽**：尖点朝圆心、距圆心 19.6（离盖孔壁 1.38）；外边沿机身圆角内缩 2.2 壁厚；半角 32°；深 3 mm；侧壁 45° 斜切；轮廓角 R1.2
- 边中点到盖孔的壁厚 1.03 mm，这是实物那一圈"薄边"

## 与 rev-004 的差异

| 项 | rev-004 | rev-005 | 参数名 |
|---|---|---|---|
| 机身 | 三片独立泪滴叶片 | 一块圆角三角整体 | `CORNER_R` `SIDE_SAG` |
| 叶片凹坑 | 删掉了 | **恢复**，三角凹槽尖朝圆心 | `POCKET_*` |
| 机身厚度 | 11.5 | 12.0 | `BODY_H` |
| 台面占比 | 0.70 | **0.797** | `DISC_RATIO` |
| 楔环外沿 vs 机身面 | -0.94 | -0.15（齐平） | 派生 |
| 材质 Base Color | 偏白 | (0.78, 0.79, 0.80) | `STEEL_BASE` |
| 平盘 | – | Roughness 0.30，径向各向异性 0.7，年轮纹 scale 6 + distortion 0.3 | `ROUGH_DISC` `ANISO_DISC` `RINGS_*` |

盖体其余参数（24 楔 / 25° / 高出 1.5 / 暗缝 0.8 / 0.5 倒角）与 rev-004 相同，不动。

## 允许调的范围

只改 `P`，不改函数体。每次只调一个量，重跑脚本，对比白模顶视图：

- 三个角太圆、像三叶草 → `CORNER_R` 7.0
- 三条边想更贴盖 → `SIDE_SAG` 2.5（注意壁厚会掉到 0.03，需同时 `GAP` 0.6 或放弃）
- 凹槽太小 → `POCKET_HALF` 36，`POCKET_WALL` 2.0；报错说明射线打不到外弧，回退
- 凹槽想开口连到暗缝（实物疑似如此）→ `POCKET_APEX` 17.5，会打穿盖孔壁，先出白模确认
- 角部外沿想要更大的滚边（实物有明显"钩"感）→ 在 `SP_Body` 上再加一个 Bevel，width 2.0，Limit Method: Weight，只给三个角的顶面外沿边打权重
- 年轮纹太密/太稀 → `RINGS_SCALE` ×2 或 ÷2
- 盖体侧壁想更圆 → 不要改 `WEDGE_N`，那是楔数；实物侧壁本来就跟着楔走 24 边

## 不要做

- 不要在脚本输出上再加 Subdivision，会把所有切面磨掉
- 不要手动移动顶点修形，改参数重跑
- 不要给楔环加各向异性或纹理，明暗交替靠几何法线
- 不要 Apply 那 5 个 Boolean，保留非破坏性，改参数重跑才有意义
- `Z_RIM - BODY_H` 必须在 -0.3 ~ +0.1 之间，超出说明 `DISC_RATIO` 或 `WEDGE_SLOPE` 被改了
