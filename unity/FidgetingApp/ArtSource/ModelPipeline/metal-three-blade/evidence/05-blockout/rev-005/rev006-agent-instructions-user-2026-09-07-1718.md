## A. 叶根凹坑

坐标：每叶用局部系 `u` = 沿叶片轴向指向叶尖，`v` = 切向，`z` 向上。坑对称于 `v = 0`（坑尖压在屋脊线上）。

| 参数 | 值 | 定义 |
|---|---|---|
| `PK_APEX_U` | **25.0** | 顶弧圆心到轴心距离（mm）。坑尖最远点 = 25 + 2.5 = 27.5，离叶尖(32.5) 留 5 mm |
| `PK_APEX_R` | **2.5** | 顶弧半径，**量在坑口 z = Z_TOP** |
| `PK_HALF_ANGLE` | **26°** | 直壁相对叶片轴向的半角 → 坑口顶角 52° |
| `PK_DEPTH` | **3.2** | Z_TOP 到坑底的垂直深度；坑底 z = 9.8 |
| `PK_WALL_DRAFT` | **62°** | 直壁与水平面夹角。派生：坑底轮廓比坑口向内缩 3.2 / tan62° = **1.70 mm**，坑底顶弧 R = 0.80 |
| `PK_ARC_SEGS` | 24 | 顶弧分段，不影响形状 |
| 开口端 | `R_CAP − 3` | 刀体向轴心伸进盖孔 3 mm，保证坑向盖孔开口、没有底边墙 |
| 坑底 | 平面 z = 9.8 | 在盖孔壁处截止；因为低于盖体下沿，所以透过坑看到黑腔 |

刀体构造（脚本已实现，agent 不用手做）：坑底轮廓 + 坑口上方 2 mm 处的放大轮廓，两圈顶点桥接，Exact Boolean。**壁是平面、顶弧是锥面**，不要给刀体加 Subdivision 或 Smooth。

## B. 顶面 → 侧壁 阶梯过渡（两级）

| 级 | 参数 | 值 | 作用范围 | 形状 |
|---|---|---|---|---|
| 1 | `STEP1_WIDTH` / `STEP1_SEGS` | **1.20 / 1** | 只作用在 `bevel_weight = 1` 的边 = 机身外轮廓的"顶面 ↔ 竖壁"上沿。脚本自动按面法向打标：一邻面 n.z > 0.5、另一邻面 \|n.z\| < 0.25、且在盖缝之外 | 45° 平切面（segments = 1 就是 chamfer，**不要改成 2+ 变圆角**） |
| 2 | `STEP2_WIDTH` / `STEP2_SEGS` / `STEP2_ANGLE` | **0.20 / 2 / 35°** | 全局，所有二面角 > 35° 的锐边，包括坑口、阶梯 1 产生的两条边、盖孔沿 | 微圆角，只为出那道细高光线 |

修改器顺序（必须）：`R6_StepA_45chamfer` → `R6_Pocket_0/1/2` → `R6_StepB_break`。
Boolean 在 A 之后，所以坑会切穿 45° 带；B 在最后，所以坑口也拿到 0.2 微倒角。

断面（外轮廓处，从外向内）：竖壁 ─(0.2 圆角)─ 45°×1.2 平带 ─(0.2 圆角)─ 顶面。**两级，不是三级；1 级是平面，不是圆弧。**

## C. 刀纹（材质，不建几何）

| 面 | 材质 | 纹路 | 参数 |
|---|---|---|---|
| 臂面 / 顶面 | `SP_Steel_ArmLay`（slot 0） | 线性平行刀纹。`LAY_MODE="radial"`：线平行叶片轴向（俯视呈辐条）；`"tangential"`：线垂直叶片轴向（同心圆） | `LAY_PITCH 0.20`，`LAY_DEPTH 0.012`，Roughness 0.36 |

## D. 验收（agent 自查，全部 Workbench 白模，不开 Cycles）

1. 顶视正交：三个坑俯视为**圆顶等腰三角**，尖朝叶尖、底开口进盖孔，坑口顶角 50~55°。看到 V 字尖角 → `PK_APEX_R` 没生效；看到圆弧底边 → 刀体没伸进盖孔。
2. 顶视：坑尖到叶尖轮廓 4.5~5.5 mm。
3. 斜视（相机在盖体上方约 40 mm、朝叶尖看，模仿 f0132）：两直壁各是**一整块平面**，Workbench 上是均匀单色，不能有渐变。有渐变 → 刀体被平滑了。
4. 同一视角：透过坑能看到盖孔黑腔，且坑底沿是一条直的水平边（坑底平面与盖孔壁的交线）。
5. 外轮廓边：能数出**两条**折线（顶面/45°带、45°带/竖壁），45° 带宽 1.2。只有一条折线 → 权重没标上；一条圆弧 → `STEP1_SEGS` 被改了。
6. 控制台 `[rev006]` 四行数值与本文 A 表一致。

## E. 允许调的范围（每次只动一个）

- 坑看着太小/太尖 → `PK_HALF_ANGLE` 30，`PK_APEX_R` 3.0
- 坑看着太张、像喇叭 → `PK_WALL_DRAFT` 70
- 坑壁看着太陡、橙光壁太窄 → `PK_WALL_DRAFT` 55
- 坑尖离叶尖太近 → `PK_APEX_U` 24
- 阶梯 45° 带看着太窄 → `STEP1_WIDTH` 1.5；太宽像斗笠 → 1.0
- 刀纹方向对不上参考 → `LAY_MODE` 切另一个值；密度 → `LAY_PITCH` 0.15 / 0.25
