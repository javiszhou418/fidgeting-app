## 3D 建模约束

> [!warning] 精度说明
> 下列比例来自照片观察，只适合作为第一版 Blockout。CAD、装配或量产前必须用卡尺、重量和拆机数据复核。

- 三翼严格按 `120°` 旋转对称；先完成单翼，再围绕中心轴阵列。
- 中心指盖直径起始值：约 `0.52W`，其中 `W` 为玩具总宽。
- 主体厚度起始值：约 `0.09W`；含上下指盖总厚约 `0.20W`。
- 可见倒角宽度：`0.006–0.012W`，建议 `4–6` 段。
- 中心盖为低多边形钻切外圈 + 径向拉丝平面；拉丝方向必须沿半径展开。
- 爆炸图的零件间距只为说明结构，不代表真实装配距离或公差。

## 高光、环境光与渲染参数

| 光源 / 环境 | 参数 | 位置与作用 |
|---|---|---|
| 主光 Key | Area `120×80cm`；`5000K`；`900 lx` | 左上 45°，塑造中心盖与三翼主面 |
| 轮廓光 Rim | Strip `80×10cm`；`3200K`；`550 lx` | 右后方约 130°，形成暖橙色边缘高光 |
| 冷补光 Fill | Area `100×60cm`；`6500K`；`180 lx` | 镜头前偏左，抬起暗部但不冲淡轮廓 |
| 环境光 HDRI | Studio HDRI `0.35` | 提供连续金属反射带 |
| World | `#101216` | 深石墨背景，避免全黑反射缺失 |
| 曝光 / 色彩 | `-0.3 EV`；Filmic High Contrast | 控制银色高光不过曝 |
| 阴影 / AO | Softness `0.65`；AO `0.20` | 保留轴承层、凹槽和装配缝隙 |
| 采样 | `512 samples`；Denoise ON | 最终图建议 16-bit PNG/TIFF |

## 同类 Fidget 玩具的复用母版

1. **先固定造型**：用“正面 / 顶面、侧面、45°、动作近景”四类参考图，禁止模型自行增加孔洞或装饰。
2. **再固定机制**：明确“手指固定件”和“运动件”，分镜中的动静关系必须一致。
3. **再做材质分区**：主体、倒角、按压件、轴承、垫片分别建材质；不要用一个金属球材质覆盖全部零件。
4. **最后打光**：中性大面积主光负责形体，窄暖轮廓光负责广告感，冷补光只抬暗部。
5. **所有 3D 用图必须附参数**：至少写明 `Metallic`、`Roughness`、纹理尺度 / Normal 强度、主光色温与照度、HDRI 强度、曝光。

## 本次生成方式与最终提示词摘要

- **底图**：使用内置 ImageGen，参考原笔记中的产品截图生成。
- **精确文字和参数**：本地排版叠加，避免生成图中文字失真。
- **动作分镜提示词摘要**：同一款三翼金属 Fidget 玩具、8 格短视频分镜、依次表现微距揭示、手部入画、正面展示、侧面结构、按压、侧拨、高速旋转与 Hero 终帧；暗石墨桌面、左上中性主光、右后暖轮廓光、无文字和水印。
- **拆解图提示词摘要**：同一产品的顶视正投影、侧视正投影、45° Hero 与中心轴向爆炸图；三翼 120° 对称、中心多面径向拉丝指盖、喷砂金属主架、暗色轴承和垫片；无手、无文字、无额外结构。
