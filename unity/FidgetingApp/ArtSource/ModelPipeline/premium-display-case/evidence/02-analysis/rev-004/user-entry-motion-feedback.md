# Gate 02 rev 4 motion correction

Date: 2026-08-26

User feedback:

> 节奏感不对，然后感觉XYZ轴运动过多，过于复杂，我觉得主体是要表达入场，现在增加了过多的动销元素，让人感觉抓不住重点

Disposition:

- Reject Gate 02 rev 3 multi-axis and multi-element motion.
- Make entry the only primary action.
- Keep the assembled case front-facing and centered.
- Use screen-space vertical translation only.
- Remove roll, yaw, pitch, lateral drift and scale animation.
- Move the Pack downward only after the real case is ready.
- Allow one narrow highlight after the case settles.
- Treat all timing values as review candidates, not locked shipping values.
- Preserve one connected whole case with no explode, split, proxy or object replacement.
